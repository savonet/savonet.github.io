Uncategorized

icecast​

Namespace, error kinds and process-wide settings of icecast.server (parameters.md §7, §10). Every other part attaches its helpers to the icecast.server namespace declared here, so the entry point MUST define the server with def replaces icecast.server(parameters), which keeps them; a plain def drops them.

Type:

unit

icecast.server.access​

Ready-made access decisions of icecast.server (listeners.md §7.1 to §7.3): icecast.server.decision.access_lists and icecast.server.decision.htpasswd are public; icecast.server.connections_per_user is the per-user limit the configuration translation composes after authentication.

Type:

unit

icecast.server.addresses​

Client addresses of icecast.server (listeners.md §8 and §9). The server calls resolve with the request of every client, listener, source client or admin request alike, and the parameters read at that use; hash is the default address_hash, applied before observers see an address.

Type:

unit

icecast.server.attached​

Liquidsoap sources attached to icecast.server mounts (mounts.md §2): the server's attach_source and detach_source methods call icecast.server.attached.attach and detach, which go through the feeders of feeders.liq.

Type:

unit

icecast.server.config​

Helpers shared by the sections of the configuration translation (icecast-config.md §1, §2). A section reads its elements with the stdlib xml.* readers, whose error.xml icecast.server.config.load turns into error.icecast.server.invalid_parameters, and reports the children it does not translate with warn_children.

Type:

unit

icecast.server.decision​

Listener decisions of icecast.server (listeners.md §2, §5, §7). For each listener request the server builds the decision's input with icecast.server.decision.request and calls the mount's listener_decision with it. An outcome that admitted is released exactly once: the server calls icecast.server.decision.release with the served session's record, or with icecast.server.decision.unserved when the admission ended before the listener was served. icecast.server.decision.all composes decisions.

Type:

unit

icecast.server.events​

Events of icecast.server (observability.md §1, §3). The server creates one registry per event with icecast.server.events.create, exposes each registry's add as an on_* method, and calls fire with the event's record and the event_bindings read at that use.

Type:

unit

icecast.server.feeders​

Feeders of icecast.server mounts (mounts.md §1.1, §2; sources.md §8). A source client's connection (sources.liq) and attach_source call attach; its disconnection and detach_source call detach. Both change the mount table under the server's lock, then raise the mount's source callbacks and the source events outside it.

Type:

unit

icecast.server.headers​

Header entries of icecast.server replies (parameters.md §4.2, listeners.md §3.2). An entry is {name, value?, compute?, status?}. Parameter validation calls invalid_entry on each configured entry; the server builds every listener reply's header list with reply, over the decision's and identity headers (turned into entries by of_pairs), then the server's and the mount's entries. cors is the ready-made CORS entry set.

Type:

unit

icecast.server.listeners​

Listeners of icecast.server (listeners.md §1, §4 to §6). A mount output calls icecast.server.listeners.accept (listeners.liq) for every request; an admitted listener is a session of the mount, held in the table icecast.server.listeners.sessions() of its entry, served by connected and ended by disconnected or, when it is never served, by the on_dropped that accept hands the harbor output. Each session releases its decision once. Stats read the sessions through current, and record builds the listener record observers see.

Type:

unit

icecast.server.log_files​

Log files of icecast.server (observability.md §9). logs.liq keeps one icecast.server.log_files.file(label=...) per log and calls write with the target and rotation parameters read at that write, and reopen with the target in force from the server's reopen_logs. A failure is logged under label and never raised; every file closes at shutdown.

Type:

unit

icecast.server.log_lines​

Lines of the icecast.server log files (observability.md §10, §11, §14): access formats a finished listener session, playlist a metadata update and error a message of the server's log. logs.liq writes them.

Type:

unit

icecast.server.logs​

Logs of icecast.server (observability.md §9 to §11, §14). The server state holds icecast.server.logs.create(...): listeners.liq writes the access line of each finished session, mount_outputs.liq the playlist line of each metadata update, icecast.server.log sends a server message to Liquidsoap's log and to the error log, and reopen is the server's reopen_logs.

Type:

unit

icecast.server.mount_requests​

Listener requests for a path without a mount output (mounts.md §1.1 "A configured mount with no output", listeners.md §1 step 0). The server registers icecast.server.mount_requests.register on its port: a mount output's literal route beats this regexp route, so it sees only the paths that have no output, and those whose output is still starting.

Type:

unit

icecast.server.mounts​

Mount table of icecast.server (mounts.md §1 to §3, §6). Source clients and attached Liquidsoap sources become feeders through attach and leave through detach (feeders.liq); both, a reload, a fallbacks request and a listener request that creates a mount end with refresh, which points every mount at its fallback and shuts down the mounts left with nothing to send. Every change to the table runs under icecast.server.locked. Fallback chains and refresh are in mount_chain.liq, mount outputs in mount_outputs.liq.

Type:

unit

icecast.server.mounts.buffer_size​

Mount outputs of icecast.server (mounts.md §1, §4, §8, §9; harbor icecast-server.md §2). icecast.server.mounts.create builds a mount's entry and its harbor output, reading the mount output parameters once; the output admits listeners through listeners.liq and follows its feeder, else its fallback, switching at the next frame. An output keeps buffer_size bytes of stream for its listeners: output.harbor's default buffer, raised to the burst when the burst is larger.

Type:

int

icecast.server.pages​

Pages of icecast.server (observability.md §6 to §8): the status pages (status_pages.liq), the admin pages (admin_pages.liq, admin_xml.liq), and /health and /metrics (health.liq) render a view of the stats() snapshot built here; pages.liq registers them on the server's port.

Type:

unit

icecast.server.parameters​

Validation helpers of icecast.server parameters (parameters.md §7), used by parameters.liq and mount_parameters.liq: check(field) gives the validators of one field, each raising error.icecast.server.invalid_parameters with the field's name, checked applies one to a value and use turns a getter into a () -> T validated at each call.

Type:

unit

icecast.server.prerolls​

Prerolls of icecast.server (prerolls.md). One store per process keeps loaded prerolls, the least recently used dropped past settings.icecast.server.preroll_cache_size. icecast.server.preroll_cache returns a view over it, built by the script or the configuration translation and passed to decisions: view(location) loads an operator's location, view.backend(location) one a backend chose.

Type:

unit

icecast.server.source_admin​

Mount commands of icecast.server (sources.md §6.1, §6.2, mounts.md §6.3): metadata (also /admin.cgi), killsource, manage and fallbacks. The server registers them on its port with icecast.server.source_admin.register (source_commands.liq, with manage and fallbacks); each is authenticated as the mount's source client would be, or with the admin credentials.

Type:

unit

icecast.server.source_decision​

URL services of source clients (sources.md §3.2, §7), internal helpers of the configuration translation: icecast.server.source_decision.stream_auth is a mount's source_decision, icecast.server.source_callbacks.url gives its on_connect and on_disconnect. Both POST form fields with the credentials and timeout of url-auth.md §3 and §7.

Type:

unit

icecast.server.sources​

Source clients of icecast.server (sources.md §1 to §5, §8). The server's harbor input calls icecast.server.sources.accept (source_admission.liq) for every source request and, once it is admitted, icecast.server.sources.connect with the connection; the feeder that connect builds goes to feeders.liq, which updates the mount table, raises the events and runs the mount's callbacks.

Type:

unit

icecast.server.stats​

Statistics of icecast.server (observability.md §4, §5, §13). Each mount output owns the counters icecast.server.stats.mount() creates: the listener pipeline counts sessions in them, the metadata path adds titles to its history. icecast.server.snapshot (snapshot.liq) renders the server's mounts for stats().

Type:

unit

icecast.server.url_auth​

Options of URL authentication (url-auth.md §1, §10). icecast.server.decision.url_auth resolves them per request with config(compatibility, options), since their defaults depend on the request's compatibility; url_auth_request.liq and url_auth_reply.liq read the resolved record.

Type:

unit

source.composition.default_on_select​

Default on_select for both file and live composition profiles. When ending is non-null (the ending source was preempted mid-track) and has only PCM audio content: if it has at most settings.source.composition.max_fade seconds remaining, sequences it with the starting source so it finishes naturally; otherwise fades it out for max_fade seconds. Any other content switches immediately: the body is typed for PCM audio, and the runtime type checks reject any source it builds from other content. When replay_metadata is true, replays the latest metadata on the starting source.

Type:

(
 {
   ending : source(audio='a, 'b)?,
   replay_metadata : bool,
   starting : source(audio='a, 'b)
 }) -> source(audio='a, 'b)
where 'a is a track and a track of type: pcm, pcm_s16 or pcm_f32,
  'b is an orderable type and a set of tracks to be muxed into a source

Arguments:

  • (unlabeled) (of type { ending : source(audio='a, 'b)?, replay_metadata : bool, starting : source(audio='a, 'b) } where 'a is a track and a track of type: pcm, pcm_s16 or pcm_f32, 'b is an orderable type and a set of tracks to be muxed into a source)
